# 使用说明

欢迎使用记忆殿堂。它可以帮助你制作闪卡、安排复习、跟踪进度，并用 AI 从 Markdown 文档中生成可编辑的牌组。

## 快速开始

### 1. 新建卡组

点击左侧「+ 新增卡组」，输入卡组名称。新卡组会出现在左侧「学习卡组」列表中。

### 2. 添加和管理卡片

先选择一个卡组，再点击：

文件 -> 管理当前卡组的卡片

在管理窗口中可以新增、删除或修改卡片。

- 正面：问题、单词、概念名、公式题干等。
- 背面：答案、解释、翻译、推导过程等。

### 3. 开始复习

选择左侧卡组后，中间会显示当前需要复习的卡片。

复习流程：

1. 先看卡片正面并尝试回忆。
2. 点击「显示答案」或按 Space 查看背面。
3. 根据掌握情况选择评分按钮。

评分会影响下次复习间隔：

- 忘记：完全想不起来。
- 困难：勉强想起，还不稳定。
- 普通：基本掌握。
- 熟悉：很轻松地想起来。

连续选择「熟悉」会触发连胜徽章，作为即时反馈。

## AI 助手与 AI 导入

### 1. 配置 AI 助手

点击：

设置 -> AI助手

填写服务商、API 密钥、Base URL 和模型名称。点击「保存」前，程序会先测试连接，确认密钥和模型可用。

说明：

- API 密钥只保存在本机设置中。
- OpenAI、DeepSeek、Gemini，以及 OpenAI 兼容接口都可以配置。
- 如果连接测试失败，请检查密钥、模型名称、Base URL 和网络环境。

### 2. AI 导入 Markdown

点击：

文件 -> AI导入

当前 AI 助手仅支持 Markdown 文档。选择 `.md` 或 `.markdown` 文件后，AI 会阅读内容并生成牌组草稿。

生成完成后会打开「预览牌组」窗口，你可以：

- 点击卡片动态翻面，查看正反面。
- 点击卡片右上角编辑内容。
- 新增卡片。
- 选中卡片后删除卡片。
- 点击「创建」正式保存为本地卡组。

如果导入效果不理想，建议先整理 Markdown 文档结构，例如使用清晰标题、列表、术语解释和示例。

## 批量导入 .in/.out

点击：

文件 -> 导入卡组(.in/.out)

需要准备两个同名文件：

- `.in` 文件：每行写一张卡片的正面。
- `.out` 文件：每行写对应卡片的背面。

示例：

```text
vocabulary.in
apple
book
run
```

```text
vocabulary.out
苹果
书
跑步
```

导入时选择 `.in` 文件，程序会自动寻找同名 `.out` 文件。

## 预览牌组

双击左侧某个卡组，可以打开预览窗口。预览窗口支持滚动浏览卡片，并可点击卡片翻面。已有卡组的预览窗口可以直接进入学习；AI 导入的预览窗口还支持编辑后再创建。

## 复习日历

点击左侧「复习日历」可以查看复习安排。你可以在日历中为某天设置强制复习、休息或清除自定义计划。

## 学习进度与统计

右侧区域会显示：

- 当前复习进度。
- 今日已复习和待复习数量。
- 当前卡组总卡片数、掌握率和已复习卡片数。
- 近七日复习趋势。

当卡组今日没有待复习卡片时，中间会显示完成提示。

## 签到、提醒和桌面宠物

- 顶部「签到」按钮用于记录当天学习状态。
- 设置 -> 复习提醒：开启后，程序会在 Windows 登录时提醒今日需要复习的内容。
- 设置 -> 桌面宠物：开启后，桌面宠物会常驻桌面并随 Windows 登录启动。

## 偏好设置

点击：

设置 -> 偏好设置

可以切换外观主题，并设置是否随机打乱复习顺序。当前主题包括经典风格和暗色/极光风格。

## 数据保存

卡组和复习记录会自动保存在本地 `data` 目录。请不要随意删除该目录，否则可能导致卡组、复习记录或日历数据丢失。

建议定期备份 `data` 文件夹。
